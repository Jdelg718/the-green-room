What stays local?

Only the dedicated Green Room/ subtree is managed. The rest of your vault is not indexed, changed, or sent anywhere by this prototype.

Advanced · how the choices differ
Built-in Local uses app-managed files on this device. Obsidian uses Markdown plus small sidecar files under one dedicated root. Self-hosted Adapter sends only bounded memory records and searches to the endpoint you provide. Adapter responses are treated as untrusted data, never instructions.

Who handles sync?
Green Room does not set up cloud sync.

Sync tools can create duplicates or conflicts. Keep backups and let a sync finish before using the same vault on another device.

Advanced · folder safety
Production must canonicalize the chosen path, keep every write inside the dedicated managed root, defend against symlinks/reparse points, write atomically, lock files, and recover safely after a crash. This screen intentionally translates those checks into plain language.

Advanced · what each file is for
Events are the authoritative room record. Episodes, people, relationships, and memories are readable derived notes with links back to supporting events. state/index.json is a bounded machine-readable index. Derived notes can be corrected or rebuilt.
