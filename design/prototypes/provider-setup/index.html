Local connection boundary

Model requests stay between your local Green Room runtime and the selected loopback server.

  • Keys, if required, go same-origin to the local runtime.
  • No key is stored in browser storage or a URL.
  • greenroomai.net receives nothing from this setup.

Production assumption: the backend stores only an opaque secret reference outside room data and redacts errors, logs, exports, and diagnostics.

Required model capability
Chat. JSON output, streaming, and system messages require explicit capability evidence and deterministic fallbacks.
Host invariant
Cancellation and room limits remain enforced by the local runtime, not claimed as model capabilities.
Cost / privacy
