# Direction 3 — Public Access Time Machine

**Working identity:** **GR–TV 33**, *the signal with impossible company.*

This direction treats The Green Room like a smart, underfunded local broadcast that somehow books history’s sharpest minds. It borrows FF2K’s authored confidence—named departments, a cast with distinct jobs, blunt editorial copy, and thick graphic gestures—without borrowing its layout, assets, or noir-newsroom treatment.

## Brand stance

The product is not a chatbot shelf. It is a live studio where a bounded Director decides who gets the microphone, silence is useful, and the receipts behind memory remain visible. The tone is witty and scrappy, but provenance and candidate status stay explicit.

## Naming system

- **Gallery → Signal Library:** find a mind’s frequency.
- **Room builder → Switchboard:** tune a three-person studio.
- **Memories → Tape Log:** an inspectable recording with event references, edit, and erase.
- **Relationships → Chemistry Dials:** evidence-linked changes, not opaque “vibe scores.”
- **Saved rooms → Reruns:** revisit a room without pretending it is live.
- **Start Room → Go Live:** a broadcast action with a clear three-person prerequisite.

## Mark and wordmark

The original **GR–TV 33** channel bug combines a compressed `GR` monogram, circular station identifier, and small channel notation. “33” is an invented station number that echoes a room of three selected voices and one bounded conversation. The stacked **THE GREEN / ROOM** wordmark behaves like two mismatched title-card strips. Both are CSS and live type—no copyrighted logo or image dependency.

## Visual system

- **Typography:** system Arial Black/Arial for blunt title cards; Courier New for logs, station labels, provenance, and controls. No external font requests.
- **Palette:** broadcast black `#171714`, warm off-white `#f1eedf`, studio green `#123c2d`, signal orange `#ff5b36`, and hot yellow `#f4de43`.
- **Portraits:** original CSS cut-paper constructions. They are deliberately non-likeness silhouettes: enough variation to make a cast, not enough to claim a historical face.
- **Devices:** channel bug, station ticker, pasted labels, hard registration shadows, title cards, knobs, meters, and a tape-slip memory summary.
- **Texture:** one restrained scan-line layer; no sepia, faux damage, neon haze, glass, or nostalgia sludge.

## Interaction and motion

The prototype supports category filtering, keyboard-operable cast selection, a details dialog, three-person lineup replacement, and **Go Live** navigation to the selected-room moment. Controls are at least 44px, focus is high-contrast, dialog behavior is native, and reduced-motion preference removes smooth scrolling. The layout is verified at desktop and 390px without horizontal overflow.

## Why it could win

- Memorable enough to own: the product vocabulary and channel-bug system are specific to ensemble conversation.
- Makes memory and relationships visible as branded behavior, not generic admin panels.
- Loud hierarchy stays readable and trustworthy through explicit source/status language.
- The cast can feel alive without unlicensed portraits, external assets, or generic AI imagery.

## Tradeoffs

- The station metaphor needs restraint in production; too many stickers or meters would turn useful controls into props.
- Arial Black/Courier are intentionally accessible fallbacks, but a future commissioned/open type pairing could make the identity more ownable.
- “Go Live” suggests broadcast; private-by-default language must remain close to the action so users do not infer public streaming.
- Cut-paper portraits scale safely and cheaply, but a production art system would need more silhouette variety and a documented commissioning/provenance pipeline.

## View

Open `index.html` directly in a modern browser. The file is self-contained and makes no network requests.
