First run / visible steps

Install without guesswork.

  1. Download the ZIP on an Apple-silicon Mac and expand it in Finder.
  2. Verify it in Terminal with shasum -a 256 The-Green-Room-0.1.0-alpha.1-macos-arm64.zip; the result must exactly match the published checksum above.
  3. Move The Green Room.app into Applications.
  4. Because Alpha 1 is not notarized, Control-click the app in Finder, choose Open, review the macOS warning, and choose Open only if the checksum matched.
  5. The app starts a loopback-only local service and opens its interface. Configure LM Studio or an approved cloud provider locally; greenroomai.net never receives your key or room content.
Release boundary / read before use

Evaluation means evaluation.

SUPPORT 01

Apple silicon only

This artifact targets arm64 macOS. Intel Macs, Windows, and Linux are not claimed as supported by this build.

TRUST 02

Local data boundary

Rooms and application state stay in the local macOS application-support directory. Provider disclosure occurs inside the local app.

STATUS 03

Catalog labels remain honest

Preinstalled character candidates remain separate from Official Catalog admission. Alpha packaging does not silently promote them.
