Install / Apple silicon

Four ordinary steps.

  1. Download the Alpha 1 ZIP from the button above.
  2. Expand the ZIP in Finder.
  3. Move The Green Room.app to your personal Applications folder (~/Applications).
  4. Open The Green Room normally from your personal Applications folder.

Alpha limitations / read first

Early software, narrow platform.

PLATFORM 01

Apple silicon only

This Alpha 1 build requires an Apple-silicon Mac running macOS 13 or later. Intel Macs, Windows, and Linux are not supported by this download.

ALPHA 02

Expect rough edges

This is early alpha software with incomplete workflows. Back up important local data and report reproducible problems.

MOBILE 03

No mobile app

No iPhone or iPad app is included. Native Apple mobile clients remain future work.
