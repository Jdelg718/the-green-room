Release gate / before a link appears

The artifact earns the link.

  1. A clean supported machine installs and starts the local companion from published documentation.
  2. The default listener and setup remain local, with no project account or hosted service required.
  3. Backup, upgrade, restore, export, delete, uninstall, and recovery limitations are tested and documented.
  4. Release artifacts reproduce from a clean checkout and publish independently verified checksums.
  5. Provider credentials remain local and absent from room data, events, exports, logs, diagnostics, packs, and this website.
