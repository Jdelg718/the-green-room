In build / character wizard

Build someone who holds the room.

WIZARD 01 / SHAPE

Start with tension

Define identity, voice, goals, flaws, boundaries, knowledge limits, and the pressures that make the character react rather than merely answer.

WIZARD 02 / TEST

Preview the behavior

Inspect what the pack will contain, test it locally, revise weak or unsafe instructions, and keep provider credentials and room history out of the character.

WIZARD 03 / PACK

Export one portable format

The Character Wizard will produce the same bounded, declarative .greenroom pack that local import and community review validate—never executable code.

Planned / community library

Share the pack, not your room.

  • DiscoverSearch characters by subject, voice, era, language, author, version, and review status.
  • InspectSee provenance, license, content cautions, schema version, review evidence, and an immutable digest before download.
  • Install locallyCommunity downloads are untrusted declarative data. The app downloads an exact version, validates it again on the user’s machine, previews its permissions and contents, then installs it only after explicit approval.
  • Trust stays visibleLocal-alpha candidates, Official Catalog-approved project packs, community-reviewed packs, and local unreviewed packs remain clearly distinct.
  • Private data stays homeThe library receives character-pack submissions—not provider keys, transcripts, rooms, memories, or model requests.
