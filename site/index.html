CALL 01 / THE ROOM

Ensemble first

Personas react to the room and one another. A bounded director chooses zero or one next speaker, because silence is a valid turn.

CALL 02 / THE RUNTIME

Local-first

The companion runs locally and owns room state, provider configuration, scheduling, memory, and secret references.

CALL 03 / THE MODEL

Bring your LLM

Connect your own local or cloud LLM through the local application. When you choose a cloud provider, that provider receives bounded context needed for inference.

Trust boundary / posted clearly

The public site stays out of the room.

  • Website receivesRequests for static project pages and local assets.
  • Website does not receiveProvider keys, transcripts, rooms, events, memory, pack drafts, or model requests.
  • Local companion ownsUser data, configuration, credential references, provider calls, and deletion.
  • Selected cloud provider may receiveBounded conversation and persona context disclosed by local setup.
