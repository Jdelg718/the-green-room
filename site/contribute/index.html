Contribution path / first places

Read, claim, build, verify.

  1. Read the repository’s contributing guide, security policy, architecture decision, and content and legal boundaries.
  2. Open or claim a GitHub issue before substantial work and name the owner.
  3. Use one focused branch and respect file ownership before editing shared contracts or composition files.
  4. Add tests for behavior changes and record the real verification commands and output.
  5. Open a pull request describing intent, evidence, risks, and relevant failure paths. Do not merge your own change without review.

Do not submit / hard stop

Keep unsafe material off the call board.

  • Secrets and private dataNo credentials, provider keys, transcripts, personal data, production addresses, private infrastructure, or exploit details in public issues.
  • Protected characters and likenessesNo television-character packs, copied scripts, actor or celebrity likenesses, voice clones, random web images, or false endorsement claims.
  • Executable packsPersona packs are untrusted declarative data, never a path to shell, browser, filesystem, credentials, or external messaging tools.
  • Unreviewed historyA historical name or repository directory is not Official Catalog approval. Provenance, rights basis, independent review, exact version, and digest gates still apply.

Security reports stay private.

Do not publish vulnerability details, credentials, private room transcripts, infrastructure details, or personal data in a public issue. Use GitHub’s private vulnerability-reporting or security-advisory workflow when available; otherwise contact the repository owner through GitHub and request a private channel without including sensitive details.

Project boundary / attribution

Standalone and independent.

The Green Room is inspired by Block’s Buzz. It is not endorsed by or affiliated with Block, and it is not a Buzz fork or dependency. Contributions must not imply otherwise.

The project is local-first. Users connect their own local or cloud LLM in the local application; cloud providers receive bounded context when selected. Public website code must never collect provider credentials, transcripts, or room data.
