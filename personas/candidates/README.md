# Held historical persona candidates

This directory contains reviewable candidate source that is intentionally outside the trusted built-in runtime root `personas/historical/`. Repository presence does not install, activate, publish, redistribute, or admit a pack to the Official Catalog.

Candidate packs remain declarative, non-executable data. Each exact version must pass the canonical validator, independent historical/content review, provenance and rights review, and the version-and-digest-specific Official Catalog gate before it can move into a release surface. No catalog manifest entry or public website page is implied by this directory.
